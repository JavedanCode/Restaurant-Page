# Restaurant Page – The Odin Project

This project is a dynamic restaurant website built as part of **The Odin Project** JavaScript curriculum.

It focuses on practicing DOM manipulation, modular JavaScript, and bundling with Webpack, along with clean UI design and component-based structure.

---

## 📚 About The Project

This project simulates a real restaurant website where all content is generated dynamically using JavaScript instead of static HTML.

The main goal was to strengthen understanding of:

- DOM manipulation and dynamic rendering  
- Modular JavaScript structure (ES6 modules)  
- Separation of concerns (logic vs UI)  
- Webpack bundling and asset management  
- Event handling and page navigation  
- Creating a Single Page Application (SPA) experience
